# Automated Data Analytics Agent

## Overview
A web application that automatically analyzes any
CSV or Excel dataset and generates insights, KPIs,
and visualizations — no coding required!

## Live Demo
[Click here to try it live!](https://automated-analytics-agent-fchwjf2hvpvwlnsd2thefa.streamlit.app/)

## Features
- Upload CSV or Excel files
- Auto data cleaning (duplicates, missing values)
- Auto KPI generation for all numeric columns
- 5 automatic chart types
- Analytics summary report
- Download cleaned data

## Tools Used
- Python
- pandas
- matplotlib
- Streamlit

## How to Run Locally
pip install -r requirements.txt
python -m streamlit run app.py
